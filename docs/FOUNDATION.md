# Huambo Online — Fundação

## Regras de projeto

- Este projeto começa do zero.
- O backend oficial é o Supabase `foqsmszwbhiyqqtuwypg`.
- Angola Localiza e Huambo Localiza são projetos independentes e não são dependências.
- Site e APP compartilham contratos e regras de domínio.
- Merge automático é permitido.
- Build e deploy automáticos são proibidos.
- CI pode executar validações, testes, lint e typecheck.

## Ordem de construção

1. Fundação técnica

5. Descoberta

7. Serviços

12. Administração

## Regra de segurança

Nenhum segredo de Supabase deve ser commitado. O frontend utilizará apenas a chave pública através de variáveis de ambiente.
